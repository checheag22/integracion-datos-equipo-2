# Guion de presentación — Equipo 2

La presentación final es de 14 diapositivas y dura 25 minutos. Sigue una historia sencilla: entender la pregunta, explicar la integración de datos con un ejemplo cotidiano, seguir una fila por las capas, ver la corrida SQL y cerrar con resultados y límites.

- Guion hablado completo por diapositiva: [`vinicola/Guion_Exposicion_25_Minutos.md`](vinicola/Guion_Exposicion_25_Minutos.md).
- Reparto breve por integrante: [`guion-rapido-por-integrante.md`](guion-rapido-por-integrante.md).
- Banco de respuestas del profesor: `respuestas-banco-preguntas-por-rol.md` (se usa después de exponer).

La evidencia de ejecución es la captura de sqlcmd y el log de la corrida en SQL Server 2022. Las imágenes de los diagramas son ilustrativas y se generaron como imágenes; no son resultados de una interfaz ni reemplazan la evidencia del SQL.
